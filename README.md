# 다포기하지마 0.4 PWA

아이폰 Safari에서 사용할 수 있는 7일 자가사용 파일럿입니다.

## 포함 기능
- 프로젝트 카테고리 / 현재 단계 / 이번 목표 설정
- 현재 단계 기반 '다음 한 걸음'
- '뭘 해야 하지?' 구조대
- '너무 어려워' 행동 축소
- 했어 / 조금 했어 / 못 했어
- 포기 이유 선택
- 구체적인 칭찬
- 선택적 한 줄 메모
- 타임라인
- 복귀 횟수 / 사용일 기록
- localStorage 저장: Safari를 닫고 다시 열어도 기록 유지
- PWA manifest + service worker

## 아이폰에서 실제로 쓰는 방법
이 폴더를 HTTPS 정적 호스팅에 올려야 합니다.
예: GitHub Pages / Netlify / Cloudflare Pages 등.

배포된 주소를 iPhone Safari에서 연 뒤:
1. 공유 버튼
2. '홈 화면에 추가'
3. 홈 화면의 '다포기' 아이콘 실행

중요: ZIP 파일 자체를 iPhone에서 여는 것만으로는 PWA 설치가 되지 않습니다.
PWA 기능과 서비스워커는 HTTPS 웹주소에서 동작합니다.
